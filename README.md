# hadra.eu — holding page

Temporary one-page site until the full website goes live (after her alta and a professional address are in place).

## Before uploading
Replace `[CORREO]` (2 places in `index.html`) with the contact email.

## Upload
Upload the *contents* of this folder to the `hadra.eu` repository (including `fonts/`, `CNAME`, `.nojekyll`). Only these files go in the public repository: the full site (hadra-web.zip) stays offline until launch, because everything in a public repository can be read, and any page in it would be published at hadra.eu.

Pages, custom domain, HTTPS and DNS: same steps as in the full site's README.

## Switching to the full site later
Delete `index.html` here and upload the full site's files (fill in the legal-page placeholders first).
